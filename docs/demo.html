Kintsugi workspace: a demo run

A team of agents with their own files, secrets, permissions, schedules and web apps. When one of an agent's tool calls fails, it writes a lesson and remembers it.

This page is a recording of python examples/workspace_demo.py. The model is a scripted stand-in, so it shows the workspace's behaviour, not how well any real model performs. Whether lessons improve a real agent is not yet measured.

1. A request that first fails, then recovers (and writes a lesson)

you @alice read plan.txt for me
alice I could not find plan.txt, so I created it.
-> alice's lessons: ['When a file may not exist, list the folder before reading it.']

2. A risky tool waits for approval; the secret is used but never shown

you @alice check how long the demo key is
alice I need approval to run run_python (approval #1).
-> approval #1: run_python {"code": "import os; print('key length', len(os.environ['DEM...
system @alice Your request to run run_python (approval #1). A person approved it and it finished (ok). Output: key length 26
alice The demo key is 26 characters long.

3. A web app published by an agent

you @alice publish a hello app
alice I need approval to run publish_app (approval #2).
system @alice Your request to run publish_app (approval #2). A person approved it and it finished (ok). Output: published at /apps/alice/hello/
alice Published. It is at /apps/alice/hello/.
-> file exists: True

4. Two agents talking in a room

you @alice ask bob to review the plan
alice @bob please review plan.txt
bob Reviewed: the plan looks fine.

5. A scheduled job

you @alice schedule a weekday standup
alice I need approval to run schedule (approval #3).
system @alice Your request to run schedule (approval #3). A person approved it and it finished (ok). Output: scheduled job 1: '0 9 * * 1-5' in team
alice Done: I will post the standup every weekday at 09:00.
cron-1 @alice post the daily standup
alice Good morning, standup time!
